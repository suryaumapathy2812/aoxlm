# Indian English L1 Transfer Patterns Reference

## Purpose

This document helps CEFR raters distinguish between:
- **L1 Transfer Patterns**: Valid Indian English features (DON'T penalize)
- **Actual Errors**: Grammar/vocabulary mistakes (DO count for Accuracy)

---

## General Principle

> Indian English is a legitimate variety of English. Many patterns that differ from British/American English are systematic L1 influences, not errors.

**Rule**: If a pattern is systematic across many speakers of the same L1, it's likely L1 transfer. Don't penalize it.

---

## Hindi L1 Patterns (UP, MP, Bihar, Rajasthan, Delhi)

### Valid Patterns (Don't Penalize)

| Pattern | Example | Notes |
|---------|---------|-------|
| Progressive overuse | "I am having a car" | Hindi uses progressive more broadly |
| "itself" emphasis | "Delhi itself is beautiful" | Emphatic marker from Hindi "hi" |
| Stative progressives | "I am knowing him" | Standard in Indian English |
| "only" as emphasis | "I only told him" | Can mean "I definitely told him" |
| Question tags | "You are coming, no?" | "na" tag from Hindi |

### Actual Errors (Do Count)

| Error Type | Example | Correction |
|------------|---------|------------|
| Subject-verb agreement | "He go to school" | "He goes to school" |
| Article misuse | "He is engineer" | "He is an engineer" |
| Preposition errors | "I am angry on him" | "I am angry with him" |

## Tamil L1 Patterns (Tamil Nadu)

### Valid Patterns (Don't Penalize)

| Pattern | Example | Notes |
|---------|---------|-------|
| Reduplication | "small small", "very very" | Emphasis through repetition |
| "only" emphasis | "Chennai only" (= definitely Chennai) | Emphatic marker |
| Topic-fronting | "That book, I have read" | Topic-comment structure |
| "itself" emphasis | "Today itself I will finish" | From Tamil "-ee" suffix |
| "one" as filler | "That one person came" | Demonstrative extension |

### Actual Errors (Do Count)

| Error Type | Example | Correction |
|------------|---------|------------|
| Word form confusion | "clearful" | "clear" |
| Tense mixing | "Yesterday I go" | "Yesterday I went" |
| Subject-verb agreement | "We runs" | "We run" |

## How to Apply This Guide

### For Fluency Rating

- Reduplication ("small small") → **May affect fluency perception** but don't over-penalize
- Natural pauses vs excessive pauses → Focus on communication flow

### For Range Rating

- Limited vocabulary is still limited, regardless of L1
- But understand that "having" constructions are valid range

### For Accuracy Rating

- **Don't count**: Systematic L1 patterns listed above
- **Do count**: Random errors, invented words, broken grammar

### For Phonology Rating

- Indian English has its own phonological system
- Retroflex consonants are a feature, not an error
- Focus on intelligibility, not "native-like" pronunciation

### For Coherence Rating

- Use of "So" heavily → Common discourse marker in Indian English
- Topic-fronting → Valid discourse structure
- Focus on logical flow, not specific connectors

## Quick Decision Tree

```
Is this pattern...
│
├─ Systematic across many speakers of this L1?
│   ├─ YES → Probably L1 transfer → DON'T PENALIZE
│   └─ NO → Check further
│
├─ Random/idiosyncratic?
│   ├─ YES → Probably an error → DO COUNT
│   └─ NO → Check further
│
├─ Does it impede communication?
│   ├─ YES → Consider impact on rating
│   └─ NO → Lean toward accepting it
│
└─ When in doubt → Note it, discuss in calibration
```

## Examples from Real Student Data

### Example 1: Tamil L1 Student (A2)

> "I grew up in Chennai only. from my childhood, it was a small small place. but later but later I shifted into a new place."

| Pattern | Classification | Reasoning |
|---------|---------------|-----------|
| "Chennai only" | L1 transfer ✓ | Tamil emphasis marker |
| "small small" | L1 transfer ✓ | Tamil reduplication |
| "but later but later" | Fluency issue | Repetition/hesitation |
| Missing capital "from" | Minor error | Transcription artifact |

**Rating**: Fluency A2 (hesitations), Range A2 (limited), Accuracy A2 (some errors)

### Example 2: Hindi L1 Student (B1)

> "I am having many friends in Delhi itself. We are knowing each other from childhood only."

| Pattern | Classification | Reasoning |
|---------|---------------|-----------|
| "am having" | L1 transfer ✓ | Hindi progressive use |
| "Delhi itself" | L1 transfer ✓ | Hindi emphasis "hi" |
| "are knowing" | L1 transfer ✓ | Stative progressive (valid in Indian English) |
| "from childhood only" | L1 transfer ✓ | Emphasis construction |

**Rating**: This would be higher rated because the "errors" are actually valid Indian English.
